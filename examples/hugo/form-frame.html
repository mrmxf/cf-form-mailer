{{- /* form-frame — embed a cf-form-mailer Worker in a Hugo page. Install: save as layouts/_shortcodes/form-frame.html, and paste examples/css/form-frame.css into your stylesheet. Use: {{< form-frame src="/forms/contact/" title="Contact form" >}} Params src required path of the form. The frame loads it with ?embed=1, which drops the form's own header, h1 and footer; the fallback link uses the plain path, the full standalone page. title required the iframe's accessible name, announced when a screen reader enters the frame Height: the Worker is routed on the site's own domain, so in production the frame is SAME-ORIGIN and the script below sizes it to fit — no scrollbar inside the page. It re-fits on every load, so a validation error or the thank-you page after a POST fits too, and on those later loads it scrolls the frame into view. Anywhere the route does not exist — a preview host, `hugo server` — the frame is cross-origin or a 404, reading it throws, and the CSS min-height stands. The link under the frame is the way out in that case. */ -}} {{- $src := .Get "src" | default "" -}} {{- $title := .Get "title" | default "" -}} {{- $page := .Page -}} {{- if not $src -}} {{- errorf "form-frame: `src` is required (called from %s)" $page.File.Path -}} {{- end -}} {{- if in $src "?" -}} {{- errorf "form-frame: `src` must be a plain path, it gets ?embed=1 appended (called from %s)" $page.File.Path -}} {{- end -}} {{- if not $title -}} {{- errorf "form-frame: `title` is required for an accessible iframe (called from %s)" $page.File.Path -}} {{- end -}}

Form not showing? Open the form on its own page.
