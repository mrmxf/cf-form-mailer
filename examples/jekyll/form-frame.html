{%- comment -%} form-frame — embed a cf-form-mailer Worker in a Jekyll page. Install: save as _includes/form-frame.html, and paste examples/css/form-frame.css into your stylesheet. Use, in a page or post: {% include form-frame.html src="/forms/contact/" title="Contact form" %} Params src required path of the form. The frame loads it with ?embed=1, which drops the form's own header, h1 and footer; the fallback link uses the plain path, the full standalone page. title required the iframe's accessible name Liquid cannot fail a build the way Hugo's errorf does, so a missing param leaves an HTML comment in the page and renders nothing. Check the output if the form does not appear. Height: the Worker is routed on the site's own domain, so in production the frame is SAME-ORIGIN and the script below sizes it to fit. Under `jekyll serve`, or anywhere the route does not exist, it is cross-origin, the script fails quietly and the CSS min-height stands. The link under the frame is the way out. The script is emitted once per page: {% assign %} inside an include is visible to the rest of the page, so a second include on the same page skips it. {%- endcomment -%} {%- if include.src == nil or include.src == "" -%} {%- elsif include.title == nil or include.title == "" -%} {%- elsif include.src contains "?" -%} {%- else -%}
